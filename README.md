# Nethmi Samadhi Portfolio

A responsive React + TypeScript portfolio for software engineering and Applied AI internship applications.

## Run locally

```bash
npm install
npm run dev
```

## Important personal updates

- Replace the LinkedIn placeholder in `src/App.tsx` with your real LinkedIn URL.
- When your final CV is ready, place it in `public/` and add its download link to the hero section.
- Replace the `NS` portrait placeholder later with your professional photograph.
- Confirm each project repository and live-demo link before publishing.

## Production check

```bash
npm run build
```
