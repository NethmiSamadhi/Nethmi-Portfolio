# Nethmi Samadhi Portfolio

A cinematic, responsive React + TypeScript portfolio presenting my software engineering, mobile development and Applied AI work.

## Live portfolio

[https://nethmi-portfolio-eight.vercel.app](https://nethmi-portfolio-eight.vercel.app)

## Featured projects

- SYNTRA — AI-powered personal financial management
- LAKDIWA POS — offline-first retail management
- TeamPulse — role-based weekly reporting
- CampusNav — congestion-aware campus navigation
- TechFix — Android repair service management
- BUILDORA — Java and MySQL inventory management

## Portfolio features

- Cinematic dark interface with light-mode support
- Six animated, product-style project previews
- Responsive layouts for desktop, tablet and mobile
- Smooth reveal, orbit, background and hover animations
- Skills, education journey, contact and social sections
- Accessible reduced-motion support

## Run locally

```bash

npm run dev
```
